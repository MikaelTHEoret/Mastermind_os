## 4. Diagnostic Procedures

### 4.1 Connectivity Tests
```powershell
# Test Vector Store
$headers = @{"Authorization"="Bearer $env:API_KEY"}
Invoke-RestMethod -Uri "http://localhost:8000/vector/health" -Headers $headers

# Validate Ollama
Invoke-RestMethod -Uri "http://localhost:11434/api/tags" -Method Get

# Check MCP Status
(Invoke-WebRequest -Uri "http://localhost:8001/health").StatusCode
```
